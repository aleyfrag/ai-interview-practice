# AI Interview Practice

An application that helps users practise job interviews.

## Features
- Role-based interview questions
- Voice answers
- Smart follow-up questions
- Scores and feedback for each answer
- Final feedback report
- Resume-based questions

## Technology
- Java and Spring Boot
- PostgreSQL
- LLM API
- Whisper for speech to text
- Text to speech
- RabbitMQ
- Docker after development

## Planned Services
- Interview Service: manages interviews and answers
- AI Service: handles AI and speech API calls
- Report Service: prepares final feedback reports.
